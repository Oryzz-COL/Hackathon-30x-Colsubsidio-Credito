# Demo para jurado · 120 segundos

1. **0–15 s:** abrir Signal Lab y explicar que una cédula real no activa búsquedas.
2. **15–35 s:** enriquecer `1010001001`; señalar los conectores ejecutados.
3. **35–55 s:** mostrar antes/después y tres señales de procedencias distintas.
4. **55–75 s:** leer Crédito educativo, condición, razón, WhatsApp y momento.
5. **75–90 s:** abrir el recibo de pesos; una señal máxima por familia.
6. **90–105 s:** activar el canal y mostrar el recibo enmascarado.
7. **105–115 s:** ejecutar Laura contra Nicolás: mismo perfil estático, dos ofertas.
8. **115–120 s:** cerrar: “Creasy no convierte una cédula en vigilancia; convierte señales autorizadas en una conversación relevante”.

## Frase de defensa

“Instagram fue una pista del reto, no una licencia para rastrear. Por eso demostramos el conector con datos sintéticos, consentimiento revocable y bloqueo sensible; la arquitectura queda lista para un proveedor autorizado.”
